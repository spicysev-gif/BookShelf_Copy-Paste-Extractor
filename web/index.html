Bookshelf Extractor

Paste a Bookshelf <section> below and download a clean PDF.

How to copy the section from Bookshelf
  1. Right-click directly on the chapter text (not the surrounding page chrome) → Inspect. Bookshelf renders the chapter inside an iframe; right-clicking inside it scopes DevTools to that frame.
  2. Switch to the Console tab. (Cmd ⌘ + Option ⌥ + J on Mac, Ctrl + Shift + J on Windows/Linux.)
  3. If Chrome shows a "Don't paste code…" warning, type allow pasting and press Enter. (One-time per console session — Chrome's self-XSS protection.)
  4. Paste this snippet and press Enter: 
    (() => {
  const NS = 'http://www.idpf.org/2007/ops';
  const findIn = (doc) => {
    const sections = [...doc.querySelectorAll('section')];
    return sections.find(s => s.getAttribute('epub:type') === 'division')
        || sections.find(s => s.getAttributeNS && s.getAttributeNS(NS, 'type') === 'division')
        || sections.find(s => [...s.attributes].some(a => a.value === 'division'));
  };
  const docs = [document];
  for (const f of document.querySelectorAll('iframe')) {
    try { if (f.contentDocument) docs.push(f.contentDocument); } catch {}
  }
  for (const d of docs) {
    const hit = findIn(d);
    if (hit) { copy(hit.outerHTML); return 'Copied ' + (hit.outerHTML.length / 1024 | 0) + ' KB. Paste into the extractor.'; }
  }
  const diag = docs.map((d, i) => {
    const ts = [...new Set([...d.querySelectorAll('section')].map(s => s.getAttribute('epub:type') || '(no epub:type)'))];
    return 'frame' + i + ': ' + d.querySelectorAll('section').length + ' <section> [' + (ts.slice(0,4).join(', ') || 'none') + ']';
  }).join(' | ');
  return 'NOT FOUND. ' + diag;
})()
  5. If you see Copied …, switch back here and paste (Cmd/Ctrl + V) into the box below.

Still getting NOT FOUND? The chapter iframe may be cross-origin, which the console can't reach. Install the browser extension — it uses chrome.scripting with allFrames: true and bypasses that limit.
